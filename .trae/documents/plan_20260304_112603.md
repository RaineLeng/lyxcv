基于您选择的**现代交互风**，我将为您构建一个响应式、具有动态效果的个人简历网站。

### 1. 技术栈选择
*   **核心框架**: React (使用 Vite 构建，轻量且高效)
*   **样式库**: Tailwind CSS (快速构建现代UI)
*   **动画库**: Framer Motion (实现平滑的滚动显现和交互动画)
*   **图标库**: Lucide React (现代风格图标)

### 2. 视觉设计与交互方案
*   **配色**: 采用深色模式（Dark Mode）作为主基调，搭配霓虹蓝/紫渐变作为强调色，体现科技与产品感。
*   **布局**:
    *   **头部 (Hero Section)**: 大字号展示姓名（冷语欣）与职位（产品经理），配合动态背景。
    *   **时间轴 (Timeline)**: 将您的教育经历（华东师范、北语）和实习经历（Soul、美团、爱奇艺）串联在一条垂直交互时间轴上。
    *   **数据可视化**: 将项目成果中的关键数据（如“提升30+”、“覆盖率60%”）高亮显示或使用计数器动画。
    *   **技能云**: 将 Figma, Python, SQL 等技能以标签云或动态进度条形式展示。
*   **交互**: 页面元素随滚动进入视口时带有轻微的上浮和淡入效果。

### 3. 数据结构化
我将先把你简历上的文字提取并整理为结构化的 JSON 数据（`resumeData.js`），便于后续维护和修改：
*   **Profile**: 姓名、联系方式、年龄。
*   **Education**: 学校、时间、学位、相关课程。
*   **Experience**: 公司、职位、时间、主要项目（关键产出）。
*   **Skills**: 工具、业务思维。

1.  **初始化项目**: 配置 React + Tailwind 环境。
2.  **数据录入**: 将图片中的简历内容转化为代码数据。
3.  **组件开发**:
    *   `Header` & `Hero`: 个人信息展示。

4.  **样式与动画**: 添加 Framer Motion 动画效果及响应式适配（确保手机端体验良好）。
